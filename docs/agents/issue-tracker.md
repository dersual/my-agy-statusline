# Issue Tracker: GitHub Issues

Issues for this repository are tracked in **GitHub Issues** using the `gh` CLI tool.

## Operations

- **List issues**: `gh issue list`
- **View issue**: `gh issue view <issue-number>`
- **Create issue**: `gh issue create --title "<title>" --body "<body>"`
- **Comment on issue**: `gh issue comment <issue-number> --body "<body>"`
- **Close issue**: `gh issue close <issue-number>`

## Settings

- External PRs as request surface: `false`
